# 🏠 House Price Predictor

A complete house price prediction application with a graphical user interface. This project demonstrates the full machine learning pipeline from data preprocessing to model deployment.

## Features

- 🏡 **Interactive GUI** - Easy-to-use interface for house price prediction
- 📊 **Data Analysis** - View sample data and statistics
- 📈 **Visualizations** - Feature importance and price trends
- 🤖 **Multiple Models** - Linear Regression, Random Forest, and Gradient Boosting
- 💰 **Real-time Predictions** - Instant price estimates with detailed breakdown

## Tech Stack

- **Python 3.8+**
- **Machine Learning**: scikit-learn, pandas, numpy
- **UI Framework**: tkinter
- **Visualization**: matplotlib, seaborn
- **Model Persistence**: joblib
